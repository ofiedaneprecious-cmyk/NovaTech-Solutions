# NovaTech Solutions Website

A responsive sample company website built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Preview on your computer
1. Download and unzip the project.
2. Open the `novatech-company-website` folder.
3. Double-click `index.html` to open it in your browser.

## Edit the website
- `index.html` — page content, headings, service descriptions, and contact email.
- `style.css` — colors, fonts, spacing, layout, and mobile styling.
- `script.js` — mobile navigation and current year.

### Quick customizations
1. Open `index.html` in a text editor such as Visual Studio Code.
2. Search for `NovaTech` to change the company name.
3. Search for `hello@novatech.example` and replace it with your real email.
4. Update the sample services, about text, and contact details.
5. In `style.css`, edit the variables at the top to change the colors.

## Publish it with GitHub Pages
1. Sign in to GitHub and create a **new public repository**, for example `novatech-company-website`.
2. Unzip this project on your computer.
3. In the repository, choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` (upload the files themselves, not an extra enclosing folder).
5. Click **Commit changes**.
6. Open the repository's **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select the `main` branch and `/ (root)` folder, then save.
9. Wait a minute or two and refresh the Pages settings. GitHub will show your live website address.

## Important
This is a demonstration company. Replace the sample company information and `.example` email before publishing. The contact link opens the visitor's email application; it does not submit a form to a server.
